# Feature Specification: 权限与隐私合规

**Created**: 2026-10-26
**Status**: Implemented
**Input**: `TODO.md` 横切技术前置「权限」「隐私合规」。

## Overview

把应用的权限模型与外发数据讲清楚，并让用户能在应用内查看与控制：
新增「隐私与数据」页，集中展示本机数据、可能外发的数据、权限授权状态与数据控制入口；
同时审计 `module.json5`，只声明实际使用的 normal / system_grant 权限，并写清通知 / 后台任务 /
文件 / 相册 / 剪贴板的申请时机与替代方案。

## Requirements

- **FR-001**: 应用内提供「隐私与数据」入口，说明哪些数据留在本机、哪些可能外发。
- **FR-002**: 逐项说明外发数据的触发条件与默认状态：订阅抓取、远端同步、正文翻译、系统分享、备份导出。
- **FR-003**: 展示通知授权状态、当前网络状态，并可一键进入通知 / 翻译 / 账号 / 备份设置。
- **FR-004**: 提供翻译缓存查看与清空入口（只动独立翻译缓存库）。
- **FR-005**: 联网能力默认关闭：翻译默认关、远端自动同步默认关、通知默认关。
- **FR-006**: `module.json5` 只声明实际使用的权限；通知 / 后台 / 文件 / 相册 / 剪贴板不声明多余权限。
- **FR-007**: 新增权限必须写明用途、授权方式与申请时机（见 `permissions-audit.md`）。
- **FR-008**: 仓库内提供 `PRIVACY.md`，与页内说明保持一致。
- **FR-009**: 文案中英文成对。

## Acceptance

- 设置 → 系统 → 隐私与数据可打开，各区块内容完整，无崩溃。
- 通知状态与实际系统授权一致；网络状态可显示在线 / 离线。
- 清空翻译缓存后条数归零。
- 全工程不出现未声明的权限调用；`GET_NETWORK_INFO` 只用于只读状态展示。
- `PRIVACY.md` 与实际数据流一致。
