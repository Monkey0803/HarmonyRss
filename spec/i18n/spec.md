# Feature Specification: 多语言扩展（繁體中文首批）

**Created**: 2026-10-27
**Status**: Done（繁體中文首批 + 日 / 德 / 法 / 西全量）
**Input**: `TODO.md` P2-4 语言扩展。

## Overview

在「跟随系统 / 简体中文 / English」之外新增 **繁體中文**：

- 新增 `zh_Hant` 资源目录（由 `zh_CN` 经 OpenCC s2twp 转换并检查术语）；
- 语言选项新增 `繁體中文`，`LocaleController` 设置 `zh-Hant` 应用偏好语言；
- 资源目录使用 `zh_Hant`（script 限定词），系统语言为繁体 / 手动选择时均可匹配；
- 其余 1000+ 条文案随 zh_CN 同步生成，避免只翻菜单造成中英混排。

日 / 德 / 法 / 西已按同一流程补齐：`ja` / `de` / `fr` / `es` 各 1021 条，
与 base 同 key、占位符一致，由 `tools/check-i18n.mjs` 校验。

## Requirements

- **FR-001**: 设置 → 语言包含「跟随系统 / 简体中文 / 繁體中文 / English」。
- **FR-002**: 选择繁體中文后立即切换应用语言（`zh-Hant`），无需重启。
- **FR-003**: `zh_Hant` 资源必须覆盖 `zh_CN` 的全部 key（当前 1011 条）。
- **FR-004**: 占位符（`%d` / `%s`）、英文专有名词、语言名保持可用。
- **FR-005**: 备份恢复的语言白名单接受新值，脏值回退默认。
- **FR-006**: 不改变简体 / 英文现有文案与布局。

## Acceptance

- 设置中可看到并选择「繁體中文」。
- 切换后设置页标题显示「設定」、语言行显示「繁體中文」，主要页面文案均为繁体。
- 切回简体 / English 正常恢复。
