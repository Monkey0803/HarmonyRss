# Feature Specification: 账号与云同步（同步内核第一批）

**Created**: 2026-10-27
**Status**: In Progress
**Input**: `TODO.md` P0-1 账号与云同步（第 1 / 2 / 8 项：同步模型、`SyncBackend` 抽象、设置项）

## Overview

先实现**与传输无关的同步内核**：同步模型、`SyncBackend` 抽象（`pull` / `push` / `resolve`）、
本地 Mock 后端与冲突合并规则。真实服务端（HTTP）留到下一批，只需新增一个 Backend 实现，
编排层与本地库不动。

本批同步的实体是**订阅源**与**文章状态（已读 / 收藏 / 稍后读 / 进度）**；
高亮与设置项沿用同一模型，留到下一批接入。

## Requirements

- **FR-001**: 统一记录模型 `SyncRecord`：`key`（实体稳定键）+ `kind` + `updatedAt` + `deleted` + `payload`（JSON）+ `origin`（设备节点 id）。
- **FR-002**: 实体键稳定：订阅源用归一化 URL（`feedMergeKey`），文章状态用文章本地 id（`article:<id>`）。
- **FR-003**: 文章状态按**字段级**合并：`read` / `starred` / `saved` / `progressRatio` 各自带 `at`，
      取各字段最新者；同一 `at` 时布尔取 `true`（已读 / 收藏不会被旧快照回滚）、进度取较大值。
- **FR-004**: 订阅源整体按 `updatedAt` 后写胜出；时间相同按 `origin` 字典序决定（结果对两端一致）。
- **FR-005**: 删除用墓碑记录（`deleted = true`）参与同一套 LWW 比较，不做物理删除。
- **FR-006**: `SyncBackend` 接口：`pull(cursor, limit)` / `push(records)` / `betterCursor` / `reset` / `name`。
- **FR-007**: `MockSyncBackend` 把「远端」存在本机偏好库，按自增 `rev` 分配游标，供演示与单测；
      不产生任何网络请求。
- **FR-008**: 本地同步表 `sync_records`（RDB，随 `ArticleStore` 一起建表 / 版本化），字段：
      `key` / `kind` / `payload` / `updated_at` / `deleted` / `dirty` / `rev`。
- **FR-009**: **差量采集**：每次同步前把当前订阅源与文章状态快照与本地同步表比对，只有变化项才标脏并刷新时间戳，
      因此不需要在每个写入口（已读 / 收藏 / 订阅编辑）埋点。
- **FR-010**: 同步编排顺序：拉取远端增量 → 逐条合并（合并结果与远端不一致时标脏）→ 推送（本机待推送 + 合并结果）→ 推进游标。
      **先拉后推**：后端按整条记录覆盖落库，先推会覆盖掉对端改过的其它字段，字段级合并将失效。
- **FR-011**: 应用合并结果：订阅源写回 `FeedStore` 并刷新列表；文章状态写回 `ArticleStore`（只改本地存在的文章）。
- **FR-012**: 同步默认关闭；关闭时所有功能保持纯本地。Mock 后端也需显式开启（隐私默认）。
- **FR-013**: 设置页新增「云同步（实验）」入口：开关、后端说明、上次同步时间、待推送条数、立即同步、重置模拟远端。
- **FR-014**: 同步失败不抛给 UI 崩溃：返回分类失败的摘要，页面给出提示并保留本地数据。

## Acceptance

- 开启同步后点「立即同步」，订阅源与文章状态写入模拟远端，待推送归零、状态显示上次同步时间。
- 两台设备语义：A 端标已读、B 端标收藏（时间不同）后互相同步，两端都保留两者结果（字段级合并）。
- 同一对象两端同时改动，按「时间新者胜 + 平局按节点 id」收敛，重复同步结果不再变化（幂等）。
- 远端删除的订阅在下一次同步后从本地列表移除；本地删除同样会同步到远端。
- 关闭同步后不上报任何数据；重置模拟远端只影响本机模拟库。

## Out of Scope（下一批）

- 真实 HTTP 服务端（登录 / 多账号 / 仅 Wi-Fi / 冲突提示）。
- 高亮、设置项、已读游标以外的粗粒度实体。
- 冷启动 / 回前台 / 抓取完成自动触发（本批只做手动同步）。
