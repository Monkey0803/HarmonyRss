# Feature Specification: 键盘快捷键与基础无障碍

**Created**: 2026-10-27
**Status**: Implemented
**Input**: `TODO.md` P2-4。

## Overview

为外接键盘 / 2in1 补阅读快捷键，并给列表行补充屏幕阅读器状态说明：

- 详情页：`j` / `k` 上/下一篇、`m` 切换已读、`s` 切换收藏、`/` 搜索、`Esc` 关闭查找 / 返回；
- 列表页：`/` 打开全局搜索；
- 查找条 / 半模态打开时不劫持按键；详情页根节点与 Reader Web 都处理按键，兼容焦点落在 Web 的情况；
- 同时兼容 HarmonyOS `KeyCode` 与 Linux 键值（便于外接键盘 / 自动化测试）。

## Requirements

- **FR-001**: 按键只在 `KeyType.Down` 时处理，处理完返回 true 阻止冒泡。
- **FR-002**: 查找条 / 半模态打开时，字母键不触发快捷键（输入优先）。
- `j/k` 在上一篇 / 下一篇不存在时不做动作。
- `/` 在详情页压入全局搜索页；在首页列表持焦时同样可打开搜索。
- `Esc` 优先关闭查找条；否则返回上一页。
- **FR-003**: 列表行提供「已读 / 未读 / 已收藏」无障碍描述；主要图标按钮保留/补充无障碍标签。
- **FR-004**: 字号统一使用 fp，跟随系统字体缩放；不新增固定 px 文本。
- **FR-005**: 设置页展示快捷键提示，便于发现。

## Acceptance

- 外接键盘在详情页按 j/k 可切换文章，m/s 改变阅读状态，/ 打开搜索，Esc 返回。
- 查找条打开时输入 j/k/m/s 不会触发快捷键。
- 首页列表持焦时按 / 打开搜索。
- 屏幕阅读器在列表行可读出已读 / 未读 / 已收藏状态。
