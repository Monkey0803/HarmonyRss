# Feature Specification: 远端订阅迁移 / 服务模式

**Created**: 2026-10-26
**Status**: Implemented
**Input**: `TODO.md` P0-2 收尾（服务模式与本地模式互斥提示）。

## Overview

连接远端服务后，本地订阅与远端订阅可能不一致。本功能在连接后提示本地独有源，并提供迁移页选择：

- **Merge / 合并**：远端源并入本地，本地独有源保留（默认，等同原行为）；
- **Migrated / 迁入远端**：把本地独有源逐个订阅到远端，全部成功才切换模式；
- **Remote only / 仅远端**：远端为权威，本地独有源停用但保留历史；切回 Merge 自动恢复本次停用的源。

模式按账号持久化（`subscription_mode`），后续每次同步都按模式执行；「仅远端」停用的 id 单独记录，
避免误恢复用户手动停用的源。

## Requirements

- **FR-001**: 连接成功后，若本地独有源 > 0 且从未选择模式，弹出迁移提示；不阻塞连接。
- **FR-002**: 迁移页展示本地 / 远端 / 重合 / 本地独有数量，读取失败可重试。
- **FR-003**: 三种模式可选，应用后立即持久化；账号页展示当前模式并可再次进入迁移页。
- **FR-004**: 迁入远端通过 `RemoteBackend.subscribeFeed` 实现：GReader `subscription/edit`，
  Feedbin `POST /subscriptions.json`（300 多选时取第一个候选）。
- **FR-005**: 迁入失败时保留原模式并提示失败数；重复迁移对已存在订阅幂等。
- **FR-006**: 「仅远端」模式在每次同步时强制停用本地独有源；若之后远端已有该源则自动恢复。
- **FR-007**: 切回 Merge / Migrated 时恢复本次因「仅远端」停用的源，不影响用户手动停用的源。
- **FR-008**: 不删除任何本地订阅 / 文章；不新增权限；凭据仍只存 Asset Store。
- **FR-009**: 中英文案齐备；迁移失败按网络 / 鉴权 / 订阅拒绝分类提示。

## Acceptance

- 连接一个有 3 个本地独有源的账号后出现迁移提示，可进入迁移页看到准确计数。
- 选「迁入远端」后 3 个源出现在远端订阅列表；本地订阅与历史不变。
- 选择「仅远端」后这 3 个源在订阅页显示为停用、不再抓取 / 通知，文章仍可读。
- 再切回「合并」后这 3 个源自动恢复启用；用户手动停用的其他源保持停用。
- 远端后来新增了某个本地独有源后，下一次同步会自动恢复该源。
