# Feature Specification: 发现与推荐

**Created**: 2026-10-26
**Status**: Implemented
**Input**: `TODO.md` P2-3。

## Overview

在纯本地、默认不联网的前提下补齐「发现」链路：

- 内置精选目录（科技 / 设计 / 商业 / 科学 / 独立博客 / 中文），按分类与关键词筛选，一键订阅；
- 本地「热门站点榜」与「相似源」推荐（静态热度 + 已订阅源主题标签打分，不上传订阅列表）；
- RSSHub 路由助手：把常见站点 / 个人主页地址推导为候选 RSSHub 路由，支持自建实例；
- 从剪贴板 / 浏览器书签批量导入候选源（复用安全控件与既有 feed 自动发现）。

## Requirements

- **FR-001**: 内置目录必须离线可用，订阅前不发起任何网络请求。
- **FR-002**: 分类筛选与关键词搜索覆盖标题 / 地址 / 标签；热门榜按本地热度降序。
- **FR-003**: 已订阅判定按归一化键（忽略 scheme / www / 末尾斜杠 / 锚点）。
- **FR-004**: 相似源推荐仅使用本地信息（目录标签 + 已订阅源标题 / 地址关键词），无信号时不硬推。
- **FR-005**: RSSHub 路由助手覆盖 GitHub / Bilibili / YouTube / Twitter(X) / 微博 / 知乎 / 简书 /
  Medium / Instagram / 抖音；不支持的站点给出明确提示。
- **FR-006**: RSSHub 实例地址可修改并持久化，脏值归一化后回退默认实例。
- **FR-007**: 一键订阅与批量导入逐项独立成败，失败映射为既有订阅错误文案。
- **FR-008**: 发现页入口在「订阅源」页，与标签 / 智能文件夹 / 规则入口并列。
- **FR-009**: 文案中英文齐备；不新增权限，不采集 / 上报任何数据。

## Acceptance

- 打开「发现」页可离线浏览目录、切换分类、搜索并订阅，成功后立即显示「已订阅」。
- 订阅若干目录源后，「为你推荐」出现同主题的其他源，且不包含已订阅项。
- 输入 `https://github.com/openai/openai-node` 可生成 commits / releases / issues 三条路由并可订阅。
- 从剪贴板导入书签 HTML 时能提取地址并逐个校验，给出成功 / 重复 / 失败统计。
- RSSHub 实例改成 `rsshub.example.com/` 后生成的路由使用 `https://rsshub.example.com`。
