## T0.3 修复与回归

### 修复 1：底部面板的模式切换按钮落在 `bindSheet` 手势区（阻断级）

- 现象：在「添加订阅源 / 保存网页」底部面板中，点「保存网页」标签页不会切换，而是**把整个面板关掉**（复现 2/2）。
- 原因：`bindSheet` 的 `dragBar` 占用面板顶部约 24vp 的下拉手势区，模式切换按钮贴着顶边绘制，点击被识别为下拉关闭。
- 修复：`entry/src/main/ets/pages/Index.ets` — `AddFeedPanelSheet()` 的标签行顶部内边距 `space_s`(8vp) → `space_xl`(20vp)，让按钮落到手势区之外。
- 验证：修复后点击标签中心可正常切到「保存网页」，面板不再关闭。

### 修复 2：主入口分享缺少 `want` 参数兜底

- 现象：`aa start ... --ps url <地址>`（模拟只把地址放进 want 参数的应用分享）不会预填网页保存面板；`ShareAbility` 有兜底而 `EntryAbility` 没有，两条入口行为不一致。
- 原因：`EntryAbility.handleSharedData()` 只走 `systemShare.getSharedData(want)`，失败时直接丢弃。
- 修复：`entry/src/main/ets/entryability/EntryAbility.ets` — 成功分支在分享记录没有 http(s) 地址时回退 `shareIntent.extractSharedUrls(want)`；失败分支也按 want 参数提取一次，取到地址才交给 `shareHandoff`。
- 验证：修复后发送 `--ps url 'https://wikihack.netlify.app'`，保存网页面板输入框自动预填该地址（`TextInput` 值为该 URL）。

## 环境限制（影响验收方式）

1. **模拟器 UI 自动化坐标漂移**：`devecocli ui click` 连续操作时偶发落到上一屏的坐标，导航类验收改用「先 dump layout、再按当前节点中心点击、再 dump 确认」的方式逐步推进。
2. **多设备**：`hdc list targets` 同时存在 `10.155.89.11:45679` 与 `127.0.0.1:5555`；所有 `hdc` 命令必须带 `-t 127.0.0.1:5555`，否则会打到另一台设备，造成「点击生效但截图不变」的假象。
3. **文本输入**：`devecocli ui text` / `uitest uiInput inputText` 均无法向 `bindSheet` 内的 `TextInput` 注入文本（焦点不生效），因此「保存网页」的输入类步骤改用分享参数预填 + 单测覆盖。
