# Feature Specification: 云空间备份（端云文件协同）

**Created**: 2026-10-28
**Status**: Done
**Input**: 用户决策 —— 使用华为系统备份能力，不接入端云数据同步（云数据库）

## Overview

把现有「全量备份 JSON」写进系统提供的云文件目录 `context.cloudFileDir`（el2/cloud），
由**端云文件协同**服务自动上云并同步到同一华为账号的其他设备。恢复时读取该文件，
复用既有备份合并逻辑（幂等、不删除本地数据）。

不接 AGC 云数据库：无需云侧部署、不需要开发者服务器，也不给用户新增「设置 > 云空间」里的应用开关。

## Requirements

- **FR-001**: 云备份固定文件名 `harmonyrss-cloud-backup.json`，只保留最新一份（覆盖写）。
- **FR-002**: 写入位置必须是 `context.cloudFileDir`；写入成功后由系统自动触发上云，应用不发起网络请求。
- **FR-003**: 首次写入时若云目录不存在，先 `mkdir` 再写（目录创建同样会触发端云同步）。
- **FR-004**: 可用性以「云目录是否存在」为准：不支持 / 未登录华为账号 / 未开通云空间时，
      页面只显示说明文字，不展示备份与恢复按钮；所有文件异常都折算成失败，不抛给 UI。
- **FR-005**: 恢复走 `BackupService.applyDocument`（与导入 / 快照恢复同一套合并逻辑），
      尊重页面上的「同时恢复设置」开关，且**不删除**本地数据。
- **FR-006**: 备份内容与本地快照一致：订阅 / 文章元数据与状态 / 高亮 / 标签 / 关联 / 智能文件夹 /
      规则 / 分享模板 / 白名单设置；不含正文缓存、设备路径与凭据。
- **FR-007**: 与本地快照 / 导入导出共用串行锁，避免交叉读写；锁被占用时返回 BUSY。
- **FR-008**: 每日自动快照成功后顺带写一次云空间（同样 24h 节流），默认开启，可在页面关闭；
      云目录不可用时静默跳过。

## Acceptance

- 支持云空间的设备上点「备份到云空间」后，`el2/cloud` 下出现备份文件，系统自动开始同步。
- 同一华为账号的另一台设备进入同一页面可看到「上次云备份」时间，点「从云空间恢复」后数据合并到位。
- 不支持云空间的设备上，页面显示「当前设备不可用：需 HarmonyOS 6.0.0.115+、云空间 6.0.0.300+…」，
  不出现可点击按钮，且不产生任何文件写入。
- 恢复过程中被中断 / 文件损坏时，本地数据保持不变。

## Out of Scope

- AGC 云数据库（端云数据同步）与 `cloudStructuredDataSyncEnabled`。
- 云空间里保留多份历史备份 / 版本管理。
